*Tabuada Zumbi** é um jogo educativo e de ação 2D estilo *survival top-down*, onde sobrevivência e prática de matemática se fundem! Enfrente hordas de zumbis e chefões. Quando a munição da sua arma acabar, você precisa "hackeá-la" para recarregar os pentes, resolvendo operações rápidas de multiplicação e divisão por teclado ou **comando de voz**.

---

## 🎯 Sobre o Projeto

Desenvolvido pelo professor de Química **Emanuel Dornelas**, o projeto tem como objetivo gamificar a prática de tabuada de forma dinâmica, rápida e envolvente. O jogo desafia a agilidade mental e os reflexos do jogador sob pressão constante.

---

## 🔥 Principais Funcionalidades

- 🧠 **Recarga Automática por Cálculo Matemático**:
  - Quando os pentes esvaziam, o painel de hackeamento solicita o resultado de operações matemáticas.
  - Escolha entre três modos de jogo: **Multiplicação**, **Divisão** ou **Ambos** (misto).
- 🎙️ **Reconhecimento de Voz (Web Speech API)**:
  - Responda aos problemas da tabuada apenas falando! Ao apertar a tecla `Espaço` ou clicar no botão de microfone, fale o número da resposta para recarregar sem parar de digitar.
- 💣 **Arsenal & Power-ups**:
  - **Munição Dupla**: Sistema de 2 pentes com 8 balas cada.
  - **Granadas (G)**: Eliminam hordas instantaneamente e causam grande dano a Chefões. Ganhe granadas derrotando Chefões!
  - **Escudo de Força (E)**: Garanta 10 segundos de imunidade e uma barreira repulsora contra os zumbis a cada 1 minuto de partida sobrevivido.
- 🧟‍♂️ **Inimigos & Dificuldade Progressiva**:
  - Zumbis comuns com velocidade acelerada com base na pontuação.
  - Chefões (Bosses) resistentes que aparecem periodicamente com ataques especiais.
- 🛡️ **Modo Desenvolvedor (Dev Mode)**:
  - Ativado via tecla `P` para testes, permitindo munição infinita e imortalidade.

---

## 🕹️ Controles

| Ação | Comando / Tecla |
| :--- | :--- |
| **Movimentação** | `W`, `A`, `S`, `D` ou `Setas Direcionais` |
| **Mirar e Atirar** | `Mouse` (Mover para mirar / Clique Esquerdo para atirar) |
| **Lançar Granada** | Tecla `G` |
| **Ativar Escudo** | Tecla `E` |
| **Falar Resposta (Voz)** | Tecla `Espaço` ou botão `🎙️ Falar Resposta` |
| **Inserir Resposta (Teclado)** | Teclas Numéricas (`0-9`), `Numpad`, `Enter` (OK), `Backspace` / `C` (Limpar) |
| **Modo Dev (Teste)** | Tecla `P` |
